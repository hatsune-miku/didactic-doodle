# 界面约束与验证

## 规范与依赖

桌面端和独立主题编辑器统一使用 React 19、TypeScript、SCSS 和 `@a1knla/cakeui` 0.5.0（对齐 CakeDesign revision 6）。HeroUI、Tailwind 和对应配置已移除。长期规则见根目录 [AGENTS.md](../AGENTS.md)。

规范来源：[项目规则](https://g.vanillacake.cn/s/QnQxLNG2z_6_.md)、[CakeDesign](https://g.vanillacake.cn/s/hernTCWR-k5m.md)、[CakeUI API](https://gallery.vanillacake.cn/llms-full.txt)。用户指定 CakeUI 为本项目组件库；不再引入其他 UI 样式系统。

## 设计选择

- 沿用原有粉色强调色 `#e8788a`，由 CakeProvider 派生背景、表面、文字及明暗模式。强调色仅用于主要操作、选中状态和交互反馈。两端 CakeProvider 显式使用 `foreground="light"`，粉色强调区域默认白字，不使用自动前景选择。
- 使用系统无衬线字体、13–14px 基础字号、紧凑控件密度。字体沿用 CakeUI 0.5.0 默认字体栈，中文字体排在 system-ui 之前，避开微软雅黑；代码与日志使用等宽字体并禁用连字。阴影、弹层圆角也沿用 CakeUI 默认值，不再单独覆写。
- 桌面端分左右两栏，不再有飞书小工具或设置页签，也没有品牌标题或分区标题：
  - 左栏自上而下为导入 / 主题编辑器、主题列表、操作栏。列表行包含拖动手柄、启用复选框、名称与简介，启用的主题在行尾显示合并优先级序号。
  - 操作栏左侧是飞书状态与启动 / 退出，右侧是恢复原版与应用主题。凡是会改动飞书的操作都集中在这里，进度、结果和失败原因也在这里出现。
  - 右栏是检查器，在详情和运行记录之间切换。详情展示所选主题的作者、标识、文件名和补丁内容（选择器、属性、颜色色块、自定义脚本），并提供上移、下移和移除。出现未查看的失败记录时，运行记录标签上显示红点。
  - 窗口窄于 720px 时改为单列，依次是工具栏、列表、操作栏、检查器。
- 独立编辑器分三栏，同样不画边框、没有分区标题：
  - 左栏是主题结构：主题信息在最上方，补丁按 ASAR 包分组，未填写目标的补丁标红，底部是添加补丁。
  - 中栏编辑选中项。主题信息包括名称、标识、作者和描述；补丁包括类型、ASAR 包、页面目录或文件路径、说明、样式、颜色变量、自定义脚本和开发者工具开关。
  - 右栏是实时 YAML 预览，可复制。窗口窄于 1120px 时预览移到中栏下方，窄于 720px 时改为单列。
- 编辑器不再用对话框逐项添加选择器、属性或颜色。样式直接按 CSS 文本编写（解析规则见下文）；颜色变量逐行编辑，带色块和原生取色器。
- 不使用装饰渐变、普通投影、卡片套卡片或品牌大标题。列表和检查器用表面色与画布分区，不画边框。检查器的选中标签用表面色而非强调色，强调色留给主要操作和启用状态。布局使用业务 className；动态颜色预览是内联样式的特例。
- 打开主题编辑器无需二次确认。结束飞书进程保留明确确认；App 管理对话框只在实际被系统阻止后出现。
- 没有启用的主题时，主按钮变为非强调样式的恢复原版。

## 交互与失败恢复

排序在拖动结束时持久化，拖动手柄支持上下方向键，详情中也提供上移/下移。持久化失败时列表回到库中的实际顺序，并提供重试。新导入的主题自动在详情中显示。

应用或恢复前会重新检查飞书进程。飞书仍在运行时，弹出确认，可选择退出飞书后继续，不再先报错、再让用户手动结束进程后重试。确认后发送结束请求，并在 15 秒内等待进程退出；超时或结束失败时，在对话框内显示原因并提供重试。完成后，操作栏显示结果，旁边就是启动飞书。

读取启用主题失败时停止应用，不静默忽略后恢复原版。导入、主题清单和应用错误显示原始原因；原生主题文件命令保留 IO 错误文本。权限引导用 CakeUI Dialog，支持系统设置入口、重试、Esc 关闭及焦点恢复。

运行记录使用 CakeUI LogView，向上阅读时暂停跟随，滚到底部继续；文本允许选择复制。同一秒内的相邻记录省略时间，含失败字样的记录用危险色高亮，这只是显示上的区分。移除了 Tauri 原来强制禁止所有文字选择的运行时样式。

编辑器的样式文本只接受普通规则，引号和括号内的分号、花括号按原样保留，同一选择器重复时按 CSS 规则合并。语法错误会在停止输入约 0.7 秒或离开输入框后显示行号和原因，并说明修改尚未保存；文本合法时立即写入主题，离开时整理为规范格式。ASAR 包路径和颜色变量名在离开输入框或按回车时才提交，非法或重名时保留输入并提示，Esc 还原。

编辑器连续输入同一字段只算一步撤销，离开字段后开始新的一步；文本框内的 Ctrl+Z 交给浏览器。Ctrl+S 导出 YAML。移除补丁后显示可撤销的提示，焦点回到结构列表。导出时字段按固定顺序输出，空的可选文本省略。草稿每次修改后暂存在浏览器的 localStorage 中，刷新后恢复；无法暂存时在工具栏说明原因并提醒导出，草稿无法读取时保留原文并提供复制。也可以把 YAML 文件拖进窗口导入。

主题写入是短时文件操作，沿用原生锁、校验和回滚，不提供中途强制终止写入的按钮。CakeDesign 的可选扩展不作为已全部实现的声明。

## 本地验证

```sh
yarn test
yarn test:editor
yarn format:check
yarn build
cd src-editor && yarn build
```

编辑器直接用 `cd src-editor && yarn dev` 预览，不需要模拟桥接；草稿保存在浏览器中，测试时可清空站点数据重来。

`tests/ui/desktop.html` 是开发用模拟页面，不连接真实飞书，也不参与生产打包。启动 `yarn dev` 后可访问 `/tests/ui/desktop.html`，通过 `scenario` 查询参数检查 `ready`、`empty`、`loading`、`error`、`permission`、`working`、`running`、`broken` 和 `missing`。`broken` 含一个无法读取的主题，`loading` 停在读取主题库阶段。权限场景的设置按钮仅模拟授权，`running` 场景可检查退出飞书后应用的流程。

界面检查覆盖桌面 800×600、窄窗口、浅色与深色、主题排序（含键盘）、详情、退出飞书后应用、错误重试、权限恢复，以及编辑器的空主题、导入失败、样式语法错误、颜色变量重名、移动 ASAR 包、移除后撤销、草稿恢复、拖放导入、撤销/重做和 YAML 导出。真实 macOS 授权和飞书修改验收依照 [MACOS.md](MACOS.md)。
